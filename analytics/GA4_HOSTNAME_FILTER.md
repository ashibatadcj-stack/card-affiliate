# GA4 ホスト名フィルタ設定手順

## 背景

GA4 のレポートに、旧 GitHub Pages URL（`/card-affiliate/...`）由来のセッションが混入しています。
これらは過去のクロール・外部リンク・ブックマークから流入してくるもので、本来の `cardshindan.com` データを汚染しています。

## 目標

- **メインプロパティ**: `cardshindan.com` のみのデータを表示
- **デバッグ用**: 旧URL流入も別途見える状態を維持

## 設定手順（10分）

### ① GA4 にアクセス

1. https://analytics.google.com/ を開く
2. プロパティ「クレジットカード比較ナビ」（プロパティID: `535797638`）を選択

### ② データ ストリーム URL を確認

1. 左下の **歯車アイコン**（管理）をクリック
2. プロパティ列の **「データストリーム」** をクリック
3. ウェブ ストリームを選択（`cardshindan.com` であること）
4. URL が `https://cardshindan.com` になっていればOK
   - 違う場合は鉛筆アイコンで修正

### ③ 内部トラフィック・除外フィルタ設定（推奨）

旧パス `/card-affiliate/` 流入を「不要なトラフィック」として除外します。

1. 管理画面 → プロパティ列 → **「データ設定」** → **「データフィルタ」**
2. 右上 **「フィルタを作成」**
3. 以下を入力：
   - **フィルタ名**: 旧 GitHub Pages URL 除外
   - **フィルタの種類**: 内部トラフィック
   - **フィルタ オペレーション**: 除外
   - **パラメータ値**: 以下のページ参照URLを設定
4. **「パラメータと値」** で：
   - パラメータ名: `page_location`
   - 演算子: 「次を含む」
   - 値: `/card-affiliate/`
5. 状態: **「有効」**
6. 「保存」をクリック

### ④ カスタム ディメンション「ホスト名」を作成（オプション）

旧URL流入を別途追跡したい場合：

1. 管理画面 → プロパティ列 → **「カスタム定義」**
2. 「カスタム ディメンションを作成」
3. 以下を入力：
   - ディメンション名: `Hostname`
   - スコープ: イベント
   - イベント パラメータ: `page_location`
4. 保存

これで「探索 > 自由形式」レポートで Hostname 別の流入を比較できます。

## 検証

設定後 24〜48時間で以下を確認：

1. **レポート > リアルタイム** → 旧URLからのアクセスが計上されない
2. **エンゲージメント > ページとスクリーン** → `/card-affiliate/...` パスが消える

## 補足: 既存データへの影響

- フィルタは **将来のデータ** にのみ適用されます
- 過去データには影響しません
- 過去データをクリーンに見るには「探索」レポートでフィルタを手動適用するか、別期間で比較
